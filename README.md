# VIT Semester Result Portal (Assignment 6)

A full-stack responsive web application designed to prepare and display one-semester results of VIT students using **React**, **Spring Boot**, and **MySQL**.

---

## 🌟 Key Features

1. **4 Subject Result System**:
   - Pre-configured with: *Data Structures & Algorithms*, *Database Management Systems*, *Web Technology*, and *Software Engineering*.
   - Editable subject names and marks.
2. **MSE (30%) & ESE (70%) Calculation**:
   - Mid-Semester Examination (MSE) marks out of **30**.
   - End-Semester Examination (ESE) marks out of **70**.
   - Subject Total = $\text{MSE} + \text{ESE}$ (out of 100).
   - Grand Total out of **400** and overall Percentage (%).
3. **Automated Grade & Status**:
   - Relative/Standard VIT Grade System:
     - 90–100: **O (Outstanding)**
     - 80–89: **A+ (Excellent)**
     - 70–79: **A (Very Good)**
     - 60–69: **B+ (Good)**
     - 50–59: **B (Above Average)**
     - 40–49: **C (Pass)**
     - Below 40: **F (Fail)**
   - Clear **PASS / FAIL** status calculation (requires $\ge 40$ in all 4 subjects).
4. **Role-Based Access Control (RBAC)**:
   - **ADMIN**: Access to the Result Management Panel to create, edit, update, and delete semester results.
   - **STUDENT**: Dedicated dashboard to securely view and print their own semester marksheet.
5. **Security & Authentication**:
   - **JWT (JSON Web Token)** Stateless Bearer Authentication.
   - **BCrypt** Password Hashing for stored user credentials.
   - Protected Spring Security 6 endpoints with CORS support.
6. **Responsive Design**:
   - Fully optimized for desktop, tablet, and mobile browsers.
   - CSS Print Media styling for clean PDF export / printing.

## 🚀 How to Run the Project

### 1. Database Setup (MySQL)
Run the following SQL in MySQL Workbench or MySQL CLI:
```sql
CREATE DATABASE vit_result_db;
```
*(The schema and tables are auto-generated by Spring Boot Hibernate).*

### 2. Backend Setup (Spring Boot)
1. Verify `backend/src/main/resources/application.properties`:
   ```properties
   spring.datasource.url=jdbc:mysql://localhost:3306/vit_result_db?useSSL=false&serverTimezone=Asia/Kolkata&allowPublicKeyRetrieval=true
   spring.datasource.username=root
   spring.datasource.password=12345678  # Update with your MySQL password if needed
   ```
2. Run backend from the `backend` folder:
   ```bash
   mvn clean spring-boot:run
   ```
   *Backend will run on `http://localhost:8080`.*

### 3. Frontend Setup (React + Vite)
1. Navigate to the `frontend` folder:
   ```bash
   cd frontend
   npm install
   npm run dev
   ```
2. Open your browser at:
   ```
   http://localhost:5173
   ```

## 📡 REST API Summary

| Method | Endpoint | Access | Description |
| :--- | :--- | :--- | :--- |
| `POST` | `/api/auth/register` | Public | Register new student account |
| `POST` | `/api/auth/login` | Public | Authenticate user & receive JWT token |
| `GET` | `/api/results/me` | Student & Admin | Get current logged-in student's marksheet |
| `GET` | `/api/results` | Admin Only | Get all students' results |
| `POST` | `/api/results` | Admin Only | Prepare / save a new semester result |
| `PUT` | `/api/results/{id}` | Admin Only | Update an existing student result |
| `DELETE` | `/api/results/{id}` | Admin Only | Delete a student result |
